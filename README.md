# 📦 Inventory Management System (Python)

A console-based **Inventory Management System** built using **Python** and **SQLite**. This application enables users to efficiently manage products, monitor inventory, record sales, generate reports, and export inventory data to CSV.

---

## ✨ Features

- ➕ Add new products
- 📋 View all products
- 🔍 Search products by name
- ✏️ Update product stock
- 💰 Record product sales
- 📊 Generate monthly sales reports
- ⚠️ Display low stock alerts
- 📦 Generate restock reports
- 🗑️ Delete products
- 📁 Export inventory data to CSV

---

## ▶️ How to Run

1. Clone this repository.
2. Open the project in PyCharm or Visual Studio Code.
3. Run `database.py` once to create the database and tables.
4. Run `main.py`.
5. Select an option from the menu and start managing the inventory.
